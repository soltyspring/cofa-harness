## 되돌린 시도
> 메인이 되돌렸거나 같은 오류가 두 번 난 시도를 기록한다. 기각한 아이디어와 실제 적용 후 실패한 변경을 구분한다.
> 복구 후 관련 검사를 다시 실행한다. 커밋 전체를 되돌릴 때는 대상 변경과 다른 세션의 작업을 확인하고 git revert 등으로 이력을 남긴다. 미커밋·혼합 변경은 필요한 부분만 복구하며 reset --hard나 일괄 덮어쓰기로 다른 변경을 버리지 않는다.
> 재시도는 이전과 달라진 조건·가설과 성공을 확인할 기준이 있을 때 한다. 진행 중인 미복구 문제는 STATE.md에도 남긴다.

| 시각 | 시도·가설 | 실패 증거 (파일·명령·결과) | 복구 범위·복구 후 검사 | 다음 접근·재시도 조건 | 관련 커밋·변경 범위 |
|---|---|---|---|---|---|
| | | | | | |

> 진행 상황(단계 · 남은 것 · 다음 할 일)은 `STATE.md` 에 둔다.
